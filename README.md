> **Неофициальный проект.** Ответ ассистента — справка по своду правил, а не позиция
> администрации GTA5RP. В спорных ситуациях решение всегда за администрацией.

---

## Возможности

- **Ответы по базе, а не «из головы».** Ассистент видит только найденные пункты правил
  и обязан ссылаться на них: `[п. 6.9]`, `[ст. 12.3]`. Если ответа в базе нет — так и скажет.
- **Защита от выдуманных номеров.** Каждая ссылка в ответе сверяется с найденными
  фрагментами; если модель сослалась на пункт, которого там не было, под ответом появится предупреждение.
- **Вся законодательная база.** Правила проекта и серверов, Конституция, Уголовный,
  Уголовно-административный, Административный, Процессуальный, Дорожный и Гражданский кодексы,
  законы об обороте оружия, об ОГП, о противодействии терроризму и ещё два десятка законов.
- **Игровой сленг.** «Меня убили просто так на респе» находит пункт про DM и SK,
  «протаранили машиной» — про DB (DriveBy).
- **Оверлей поверх игры** по `Alt+X` — спросить, не сворачивая GTA.
- **19 серверов проекта.** Поиск по общим документам плюс правилам выбранного сервера.
- **Любая модель OpenRouter**, включая бесплатные. Работа через VPN или прокси.
- История чатов, туториал при первом запуске, источники под каждым ответом.

## Установка

1. Скачайте `GTA5RP-Assistant-Setup-x.x.x.exe` со страницы [Releases](../../releases/latest).
2. Запустите установщик. Приложение не подписано сертификатом, поэтому Windows SmartScreen
   покажет «Неизвестный издатель» — нажмите **Подробнее → Выполнить в любом случае**.
3. При первом запуске откроется туториал.

### Что понадобится

**Ключ OpenRouter.** Создаётся бесплатно на [openrouter.ai/keys](https://openrouter.ai/keys).
Ключ вводится в «Настройках», шифруется средствами Windows и хранится только на вашем компьютере.

**Доступ к openrouter.ai.** Из России сайт часто блокируется провайдером — ошибка выглядит
как `403 Access denied by security policy`. Варианты в «Настройки → Соединение»:

| Режим | Когда использовать |
|---|---|
| Напрямую | VPN включён на весь компьютер (режим TUN) |
| Системный прокси | прокси прописан в настройках Windows |
| Свой прокси | указать локальный порт VPN-клиента, например `socks5://127.0.0.1:10808` |

Типовые порты: Hiddify — `12334`, v2rayN — `10808`, Nekoray — `2080`.
Кнопка «Проверить соединение» покажет, проходит ли запрос и валиден ли ключ.

## Оверлей в игре

`Alt+X` открывает компактное окно ассистента поверх игры. Enter — спросить, Esc — скрыть.
Окно можно перетащить за шапку, сочетание клавиш меняется в настройках.

> GTA должна быть запущена в режиме **«Оконный без рамки»**. В полноэкранном (эксклюзивном)
> режиме Windows не показывает поверх игры никакие окна — это ограничение системы.

Оверлей — обычное окно Windows: он не читает память игры, не внедряется в её процесс
и никак на неё не влияет. Тем не менее перед использованием стоит свериться с актуальными
правилами проекта о стороннем ПО.

## Как это работает

```
вопрос ──► поиск по базе (BM25 + словарь сленга) ──► 10 подходящих пунктов
                                                           │
            ответ со ссылками ◄── модель OpenRouter ◄──────┘
                   │
                   └──► проверка: все ли номера пунктов были в найденном
```

1. **База правил** скачивается с форума проекта: сборщик проходит по оглавлению раздела
   «Законодательство», забирает первый пост каждой темы, переводит в текст и режет на пункты
   с номерами. Из нескольких редакций одного документа остаётся самая полная.
2. **Поиск** — BM25 с русским стеммером. Запрос расширяется словарём игрового сленга
   (`config/glossary.json`), а в юридических вопросах («сколько лет», «штраф», «статья»)
   приоритет получают кодексы.
3. **Модель** получает только найденные пункты и жёсткий промпт: отвечать по ним,
   номера не выдумывать, при отсутствии ответа честно сказать об этом.

Всё работает локально: запросы уходят только в OpenRouter, никакого собственного сервера нет.

## Сборка из исходников

Нужен [Node.js](https://nodejs.org) 20 или новее.

```bash
git clone https://github.com/<ник>/gta5rp-assistant.git
cd gta5rp-assistant
npm install
npm run rules:update     # скачать и разобрать базу правил
npm run dev              # запустить в режиме разработки
```

Собрать установщик:

```bash
npm run dist             # результат в release/
```

> **Ошибка `Cannot create symbolic link` при сборке** — Windows не даёт обычному пользователю
> создавать символьные ссылки, а они есть в архиве инструментов electron-builder.
> Включите **Параметры → Система → Для разработчиков → Режим разработчика** или один раз
> запустите сборку из терминала от имени администратора.

### Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | приложение в режиме разработки |
| `npm run rules:update` | скачать и разобрать базу правил |
| `npm run eval` | проверить поиск на 50 контрольных вопросах |
| `npm run eval -- -v` | то же с разбором провалов |
| `npm run eval:answers` | прогнать вопросы через модель и поймать выдуманные номера пунктов (нужен `OPENROUTER_API_KEY`) |
| `npm run dist` | собрать установщик |

### Качество

`npm run eval` прогоняет 50 контрольных вопросов по 10 категориям (убийства, отыгровка,
транспорт, оружие, УК, АК, права, гос. структуры, аккаунт, экономика) и проверяет,
находится ли нужный пункт. Текущий результат — **94%**, из них 86% в первой тройке.

### Добавить документ или сервер

Источники — в `config/sources.json`. Для правил нового сервера найдите на форуме тему
«Правила сервера <название>» и добавьте запись; `scope` должен совпадать с `id` сервера
из `config/servers.json`. Тип `index` — оглавление: сборщик сам пройдёт по всем ссылкам внутри.

Если форум закрыт Cloudflare, сохраните страницу из браузера (`Ctrl+S` → «Веб-страница,
только HTML») как `data/raw/<id>.html` — сборщик возьмёт её оттуда.

## Структура

```
src/
  main/            главный процесс Electron: окна, IPC, OpenRouter, прокси, оверлей
  preload/         мост между окнами и главным процессом
  renderer/        интерфейс на React: чат, правила, настройки, оверлей, туториал
  shared/          поиск и промпт — общие для приложения и тестов
scripts/
  fetch-rules.mjs  сборщик базы правил
  eval.mjs         проверка качества
  lib/             разбор HTML форума и нарезка на пункты
config/            источники, серверы, словарь сленга
tests/             контрольные вопросы
```

**Стек:** Electron, React, TypeScript, Tailwind CSS, Framer Motion, OpenRouter API.
